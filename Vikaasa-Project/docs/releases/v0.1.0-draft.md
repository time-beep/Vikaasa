# Vikāsa v0.1.0 — Historical Release Draft

**Status:** draft only; this was not published as an official release. Kept as historical project context.

## Snapshot

The draft described the software pipeline and noted that backend API/storage code, frontend dashboard, and modular firmware implementation were present. Its build/test observations were a snapshot from the earlier repository state and should not be interpreted as current verification. Check the current source, root GitHub Actions workflow, and component READMEs for the latest supported commands and limitations.

## Explicit limitations at the time of the draft

- Physical sensor calibration and real-world measurement accuracy were not validated.
- End-to-end ESP32 connectivity was not established by automated software tests.
- ML inference and production model scoring were not connected to the system.
- Alert generation and production authentication were not implemented.
- Supabase/Firebase live deployments required external credentials and database configuration.

This document is retained for context, not as a release announcement or warranty of present-day behaviour. See [`../README.md`](../README.md), [`../system_architecture.md`](../system_architecture.md), [`../api.md`](../api.md), and the component READMEs for current documentation.
